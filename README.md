# nekorisu

把你和 AI Agent（Claude Code、Codex）的会话原样存到你自己选的存储里，需要时按行读回来，逐字节恢复。

## 安装

点代码框右上角复制，原样发给你的 Agent：

```text
请读 https://raw.githubusercontent.com/NEKO-CwC/nekorisu/main/docs/agent-install.md ，照着它帮我安装 nekorisu。每一步先告诉我要做什么，等我同意再动手。
```

Agent 会一步一步告诉你要做什么，你同意了它才会动手。存储密码和令牌都由你自己在终端里输入，不经过 Agent。

想先看看它会做什么：[`docs/agent-install.md`](docs/agent-install.md)。
